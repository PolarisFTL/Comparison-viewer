# 中文使用教程

## 1. 主机启动

源码版支持 Windows 和 macOS，主机需要 Python 3.9+，运行时只用标准库。Windows 双击 `Start-Windows.bat`；macOS 双击 `Start-macOS.command`。启动器查找可用 Python，打开默认浏览器，通常进入 `http://127.0.0.1:8770/setup`。保留启动器控制台；关闭浏览器不等于退出服务。

macOS 需要先解压完整项目到可写目录，安装 Python 3.9+，再双击 `.command`。没有脚本执行权限时，可在该项目目录执行 `chmod +x Start-macOS.command Start-LAN-macOS.command`，或执行 `bash Start-macOS.command`。系统阻止下载内容时，通过系统界面核实并允许你信任的项目，不关闭全局安全保护。Python 图形目录选择组件因安装发行版而异，页面路径输入可作为备用。逐步教程与 Tk、Finder 路径及安全提示见 [macOS 从零启动指南](MACOS.md)。

若使用实际发布的便携包，按包内说明启动；便携包与源码版的依赖不同。macOS 的 Intel / Apple Silicon 构建不能互相冒充原生构建，且未签名应用可能需要用户确认。

Windows 2.1 便携 EXE 已完成构建与实际启动／PNG 导出测试，在只有 Windows PATH、没有可调用 Python／Node 的环境仍可启动。macOS 当前交付源码，已准备系统适配和 CI 构建流程，但本轮没有 macOS 实机或远程 CI 执行记录。Windows／macOS 原生目录对话框已实现，GUI 操作尚未逐项实测，不将代码存在视为对话框验收通过。

## 2. 先配置数据

首次及后续启动均先显示配置页。可以复用上次配置，也可以添加方法、删除方法、更改顺序、显示名称或基准目录。也可先使用页面的合成示例验证功能，不需要公开真实实验图。

1. 输入数据集名称，例如“实验 A 定性对比”。
2. 添加 2～24 个方法目录，选择本机已有图片文件夹。
3. 方法显示名称可自由更改，例如“Input”“Baseline”“Ours”“GT”；更改名称不影响真实文件夹。
4. 选定基准目录。其每张图片定义一行样本，其他目录都向它匹配。
5. 点击目录检查／生成索引，查看各目录图片数量、成功匹配数、缺失和歧义。
6. 确认报告后进入查看器。图片增删后，返回配置页重新生成索引。

目录选择发生在运行服务的主机，不是远程访问者的电脑。浏览器不能未经授权枚举任意文件夹；由主机服务发起的原生目录选择或主机手动路径输入完成配置。远程用户不能借此扫描主机磁盘。

## 3. 文件必须如何一致

推荐按同一套样本 ID 导出每个方法的结果：

```text
Input/        sample_001.jpg  sample_002.jpg  sample_003.jpg
Baseline/     sample_001.png  sample_002.png  sample_003.png
Ours/         sample_001.png  sample_002.png  sample_003.png
GT/           sample_001.png  sample_002.png  sample_003.png
```

精确文件名优先；扩展名不同时，唯一主文件名可安全对应。嵌套目录和重复文件主名要看审计报告，程序不按排序配对，也不自动猜测前后缀规则。比如同时出现 `sample_001.jpg` 与 `sample_001.png` 时，只有能唯一确认的匹配才会采用；歧义不以任选一张消解。

缺失项保留 `Missing` 占位，可以用于检查预测不全。完整比较时建议各目录使用相同样本集合。额外文件不自动成为基准样本。目录内有图像文件不表示浏览器都能解码；TIFF 等格式支持取决于浏览器，建议使用 PNG 或 JPEG。

相同样本的内容应具有可比较的视野和方向。程序保持纵横比，不会自动校准 RGB 与红外、裁掉检测框或修改坐标。几何不同的输出需由你的数据生产流程提供可靠对应。

## 4. 浏览与分析

- 每页可选 1 / 2 / 3 / 4 / 6 / 8 行，默认 4 行；每列固定一个方法。
- 文件名搜索、缺失筛选、收藏筛选和随机跳转定位样本。
- 横向滚动查看其余方法；侧栏可隐藏、拖动排序、单列查看及恢复顺序。
- `Ctrl + 滚轮` 围绕鼠标缩放；普通滚轮滚动页面；左键拖动平移，双击适应，`1:1` 查看原始像素比例。
- Synchronized Zoom 可同步同一行或当前页。同步基于归一化视野，不代表已完成空间配准。
- 详情使用原图，显示分辨率和文件名。主机可定位本地文件；远程用户不执行主机文件管理器操作。
- 框选局部区域后，对应方法同时查看同一区域；可以移动、清除或重画。原始图片不变。
- 双方法支持并排；两图几何尺寸相同时可用分割线，即使尺寸相同也请自行确认视野一致。

快捷键：`/` 聚焦搜索；输入框外 `←` / `→` 翻页；视口获得焦点时 `+` / `-` 缩放、`0` 适应；`Esc` 关闭弹窗。系统和浏览器保留快捷键可能优先处理。

## 5. 筛选记录

每行可收藏、标为已审并添加备注和多个标签。系统只记录你的判断，不自动评价模型优劣。

协作访问者首次输入共享口令和昵称，保存生成的恢复码。以后使用相同昵称需要恢复码，避免他人冒用记录。每位筛选人拥有独立标记，主机汇总推荐人数和筛选进度。多人意见不以“最后一次写入”覆盖为单条判断。

浏览器保存布局偏好；集中标记在主机 `local/workspaces/` 下的 SQLite。定期备份工作区或导出团队 JSON。复制工作区时停止服务，或使用程序备份功能，避免遗漏 SQLite WAL 中的数据。

## 6. 导出论文对比图

如果目标是先筛出少量原始结果、再到 MulimgViewer 排版，请使用 2.2 的[精选小库导出](BATCH_EXPORT.md)。它按方法复制独立图片；下文 PNG 功能生成的是拼接画布，两者不会相互替代。

在 Export Comparison Figure 选择当前页、指定样本或收藏中的部分样本，采用当前可见的方法和顺序。默认“原始像素 1:1（推荐）”保持每幅图的原始像素；“自定义总宽（会缩放）”用于明确接受缩放的固定宽度输出。先预览，再保存 PNG。

完整图像保持比例、白底和独立标题区；不在检测结果上叠加界面按钮。局部导出须明确选择区域。预览有失败计数时先检查对应单元，缺失图不会用其他样本替换。

横向／纵向间距默认各 16px，可独立调至 0-256px；外边距默认 24px，可调 0-512px。方法标题与样本编号有独立区域及字号，位于图像外。预览可切换适应视口和 100%，预览缩小不会改变 PNG 像素。

单次上限 24 样本、120 张图；桌面画布最多 4800 万像素，弱设备更严格，单边限制 16384。原像素模式超限时减少样本／方法或拆分，不会偷偷缩小。选择自定义总宽时才能主动降低宽度。Canvas 不适合拼接整个数据集。

例如十列 840px 宽的原图，仅内容就需要 8400px 总宽，加间距与边距后更宽；3200px 总宽必然缩小每幅图。PNG 无损只表示编码不额外损失信息，不能恢复缩放丢掉的像素；提高 DPI 不会增加源像素。完整解释见[中文报告](技术与使用报告-中文.pdf)或 [English report](Technical-and-User-Report-English.pdf)。

## 7. 退出、迁移与更新

通过主机页面退出服务或关闭启动器控制台；重新启动会保留配置和标记。IP 改变后重新复制邀请地址。

源图仍在原位置。迁移电脑后重新选择新路径，不直接使用旧电脑绝对路径。数据和代码分离：`local/` 不提交 GitHub。不同数据集具有独立 ID 和工作区，不要通过重用旧数据库强行合并标记。

## 8. 2.2 多人筛选后整理小库

在团队汇总中选择任意人收藏、至少 N 人推荐、有备注／标签、全队未审或全部样本，可叠加文件名查询。汇总最多显示前 200 行，批量导出范围不受这 200 行显示限制。预览默认全部方法，包含主页面隐藏列；需要时明确选择子集。

主机选择已有可写目录，程序在里面创建全新批次，不覆盖原图；成功后复制单个或全部方法目录路径。远程访问者下载 ZIP 到自己电脑，完整解压后重新准备本机路径，不能把主机的绝对路径粘贴给本机 MulimgViewer。每批附报告、路径和对应清单。

当目录之间扩展名不同，使用专用 Image File List CSV；不假改文件后缀。Missing、复制失败和不适合外部 CSV 的不完整行均有明确记录。完整流程见 [中文教程](BATCH_EXPORT.md) / [English workflow](BATCH_EXPORT_EN.md)。
