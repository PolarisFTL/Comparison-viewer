# 可信内网多人筛选

## 1. 两种启动模式

| 模式 | 启动入口 | 可访问范围 |
|---|---|---|
| 默认本机 | Start-Windows.bat / Start-macOS.command | 仅本机回环地址 |
| 明确开启内网 | Start-LAN-Windows.bat / Start-LAN-macOS.command | 授权的私有 IPv4 网段，仍需网络可达 |

默认端口 8770。命令为 `python server.py`，启用内网时追加 `--lan`；高级配置可重复指定 `--allow-subnet CIDR`，只接受合规私有范围。自动发现使用接口真实地址和掩码，不能把所有校园网都视为 /24。确切范围以主机页面／控制台为准。

不启用内网时，给别人发送 `127.0.0.1` 无效，因为它表示对方自己的电脑。开启后复制实际邀请 URL 和口令，不把示例地址当成当前 IP。

## 2. 主机与访问者

主机先在 `/setup` 选择目录并检查索引，再进入 `/viewer`。协作时使用 LAN 启动器，保留服务运行，通过邀请界面向可信同学提供 URL 与口令。

访问者不需要 Python，也不需要访问 Windows 盘符或挂载 macOS 文件夹。浏览器从受控接口读取索引内图片，没有任意本机路径读取接口。远程访问者先登录，不能配置主机目录、启动文件选择器或关闭主机服务。

首次输入口令和昵称后保存恢复码。再次使用已有昵称需用恢复码认领，不能随意抢占。共享口令用于进入工作区，恢复码用于个人身份，两者用途不同。不要把它们提交 GitHub。

各人独立收藏、备注、标签和已审状态，汇总页可按人查看、统计共同推荐和进度。多人记录不自动合并为最终判断；论文选图仍需研究者复核。团队标记可导出 JSON，主机 SQLite 集中保存。

## 3. 防火墙与校园网隔离

Windows 入站放行通常需要管理员权限／UAC。只为实际端口和所需私有网段设置范围受限的规则，避免全部网段、所有程序开放。macOS 首次允许 Python 或便携应用接收入站连接时，按系统提示操作。启动服务成功不等于防火墙已放行。

访问失败依次检查：主机页面可用 → URL 的 IP／端口正确 → 允许子网包含同学地址 → 防火墙许可 → 路由与校园网策略。客户端隔离、不同 VLAN、访客 SSID、宿舍和实验室隔离均可能阻止互通。不要通过关闭整台电脑防火墙排查。

跨网段被学校策略阻止时，使用学校认可的实验室服务器／网络路径或请管理员配置受控访问。本项目不自动启用公网隧道、路由端口转发或上传研究图。动态 IP 改变后重新分享地址，主机休眠或关闭服务后他人不能访问。

## 4. HTTP 与信任边界

这是可信内网轻量服务，默认使用 **HTTP，链路没有 TLS 加密**。有能力监听流量的攻击者可能取得口令、会话或图片；口令不能替代 HTTPS。不适合直接暴露公网或不可信公共 Wi-Fi。学校提供 HTTPS 反向代理时，由具备运维权限的人配置并确认代理地址与应用校验一致。

应用包含来源网段、允许 Host、同源 Origin、会话和变更令牌校验；图片按索引白名单访问，快照避免取错数据。主机管理和远程筛选权限分开。这些降低风险，不是专业安全审计结论。

登录后访问者可以查看和下载授权工作区图像，浏览器不能阻止截图或二次保存。仅向有权查看实验结果的人提供口令。管理页可轮换口令和失效旧会话，详情以实际提示为准。

## 5. 存储、备份与性能

配置、索引、凭据和数据库在 `local/`；每个数据集独立。布局保存在各自浏览器，标记保存在主机。清除浏览器缓存不等于备份标记，复制源码也不迁移运行记录。

导出团队 JSON；复制数据库工作区前停止服务，确保 WAL 等文件一致。恢复时保留同一数据集 ID，先备份目标。丢失恢复码由主机按明确流程处理，不通过改昵称假装恢复旧身份。

每浏览器有限并发不等于主机并发固定为 4。访问者增加后，磁盘、网络、解码和线程可能成瓶颈。先用少量同学测试，再增加人数，避免同时大尺寸导出。

## 6. 现场验证

自动测试能验证身份、越权、来源和独立标记，不能替代真实跨设备连通性。在目标校园网用第二台设备验证，记录允许子网和防火墙；macOS 防火墙、跨 VLAN 和学校策略以现场为准。

## 7. 2.2：把团队意见变成可排版的小库

团队汇总可以筛选至少 1 人收藏、至少 N 人推荐、有任意人备注／标签、全队无人已审或全部样本，文件名查询在相应结果集生效。人数按独立身份计算，汇总最多展示前 200 行，批量导出仍处理全部匹配样本。默认全部方法，包含界面隐藏列，也可明确选方法子集。

权限分为两条：主机可选择已有输出目录并创建全新批次；访问者只能把授权样本打成 ZIP，通过浏览器下载到自己的设备。访问者不能借导出指定主机任意文件路径、调用主机目录选择器或覆盖已有文件。小库中保存逐方法原文件以及可再次查看的报告与路径清单，不包含登录口令或恢复码。

主机路径只在主机有效；ZIP 解压后必须准备接收者本机路径。方法显示名会映射成跨系统安全文件夹名称，原目录不重命名。扩展名不同仍保留真实格式，通过 MulimgViewer 的显式图片清单对应，而不是改后缀。Missing 和复制失败进入报告，不用别的样本替代。

授权用户原本可以读取图像，ZIP 让这些授权图像便于批量带走，不限制其二次保存。只邀请有权访问数据的人，先确认研究数据披露范围和可用磁盘／网络空间；图像继续不上传第三方平台。操作教程：[中文](BATCH_EXPORT.md) / [English](BATCH_EXPORT_EN.md)。
