# Comparison Viewer：macOS 安装与使用指南

适用版本：2.2.1。作者：PolarisFTL 和 GPT 6 Astra；Mac 源码启动流程未经实机验收。

**当前 Mac 交付方式是源码运行：先安装 Python 3.9+，再双击 `Start-macOS.command`。当前没有已构建、已实机验证的 Mac `.app` 下载包。Windows 的 `ComparisonViewer.exe` 不能在 macOS 上直接运行。**

源码只使用 Python 标准库和本地 HTML/CSS/JavaScript，不需要 Node.js、npm、浏览器扩展或运行时 `pip install`。下载 Python 与项目时需要联网；安装完成后，本机查看功能可以离线运行。参与他人已开启的校园网协作时，你只需浏览器和对方提供的地址、口令，不需要在自己的 Mac 安装 Python。

## 1. 准备 Python

1. 打开 [Python 官方 macOS 下载页](https://www.python.org/downloads/macos/)，选择适配当前 macOS 的受支持稳定版本，版本须为 3.9 或更高。3.9 是代码兼容下限，不表示推荐新装旧版本。
2. 下载官方 `.pkg` 安装器并双击，按安装器说明完成安装。优先使用默认组件；官方安装器包含原生 Tk，供本项目的文件夹选择窗口使用。
3. 官方当前的 universal2 安装器可原生运行于其支持的 Intel 与 Apple Silicon Mac。查看具体下载页列出的系统要求，不要根据本项目的 Python 下限推断所有旧 macOS 都兼容。Python 的系统级安装可能需要管理员授权；查看器日常运行不要求管理员权限。[官方安装与平台说明](https://docs.python.org/3/using/mac.html)

安装后重新打开“终端”，检查：

```bash
python3 --version
```

应显示 `Python 3.x.x`，且版本不低于 3.9。若仍找不到 `python3`，先关闭并重新打开终端、核对官方安装是否完成。不要删除或修改 Apple 在 `/usr/bin/python3` 提供的系统组件；独立安装的 Python 可以与系统版本共存。[Python 关于 Apple 系统 Python 的说明](https://docs.python.org/3/using/mac.html)

## 2. 解压项目并首次启动

1. 下载项目源码 ZIP，完整解压，保留 `desktop.py`、`server.py`、`setup.html`、`js/`、`css/`、`assets/` 和启动脚本之间的相对位置。
2. 将项目文件夹放在当前用户可写的位置，例如个人 `Projects` 文件夹。不要直接从 ZIP 预览中启动，也不要将源码运行目录放进只读磁盘映像或系统受限目录。
3. 在 Finder 中双击 **`Start-macOS.command`**。
4. 当前源码模式会打开终端、运行本地 Python 服务，并自动在默认浏览器打开配置页，通常为 `http://127.0.0.1:8770/setup`。实际地址以终端输出为准。
5. 保留运行服务的终端窗口；关闭浏览器标签页不会停止服务。

启动脚本会先切换到脚本所在文件夹，再查找 Python，因此项目路径包含空格也不需要自行修改脚本。若未来你取得经独立构建的 `.app` 包，启动器包含对应识别逻辑；这不表示当前交付已经提供该产物。

## 3. `.command` 提示没有执行权限时

源码 ZIP 会记录启动脚本的可执行权限，但其他解压、复制或下载方式可能丢失该权限。只需为本项目两个启动脚本恢复权限，不需要 `sudo` 或递归修改其他文件。

先在“终端”定位项目目录。有两种方式：

- 输入 `cd `，注意 `cd` 后有一个空格；把 Finder 中的项目文件夹拖到终端，再按回车。拖入文件夹会填入绝对路径。[Apple 拖入路径说明](https://support.apple.com/guide/terminal/drag-items-into-a-terminal-window-trml106/mac)
- 若解压位置确实是个人 `Projects` 文件夹，可执行下面的示例；位置不同时请改成自己的项目路径：

```bash
cd "$HOME/Projects/Comparison-Viewer"
```

确认当前目录内有项目文件，然后恢复权限并启动：

```bash
ls Start-macOS.command desktop.py
chmod +x ./Start-macOS.command ./Start-LAN-macOS.command
./Start-macOS.command
```

也可以在项目目录直接运行 `bash ./Start-macOS.command`，或运行 `python3 desktop.py`。`chmod +x` 只解决执行权限；系统安全提示、Python 未安装和目录不可写属于不同问题。[Apple 关于脚本执行权限的说明](https://support.apple.com/en-bw/guide/terminal/apdd100908f-06b3-4e63-8a87-32e71241bab4/mac)

## 4. 在欢迎页选择图片目录

1. 填写数据集名称。
2. 添加 2–24 个方法，点击“选择目录”逐个选择本机图片文件夹，也可直接粘贴绝对路径。
3. 设置方法的显示名称。它只影响网页标题，不会重命名 Finder 中的文件夹。
4. 指定一个样本基准目录，点击“检查目录并建立索引”。
5. 核对图片数、成功匹配、缺失与歧义统计，再进入对比工作台。

Mac 路径使用 `/` 分隔，例如 `/Users/YOUR_NAME/experiments/MethodA`。这是占位示例，必须替换成你实际选择的目录。Windows 的盘符路径和旧电脑的 `local/config.json` 不能直接拿来作为 Mac 图片目录；请在 Mac 上重新选择路径。不要为了适配路径而更改图片文件名。

复制目录路径的方法：在 Finder 中右键文件夹，按住 **Option（⌥）**，选择“拷贝‘文件夹名称’为路径名称”，粘贴到页面输入框。该操作由 Apple 官方指南明确说明。[Apple 路径名称说明](https://support.apple.com/guide/terminal/specify-files-and-folders-apd3cf6fe02-3ec8-48f1-951f-866e52955fc8/mac)

页面输入框接收的是原始路径，不是终端命令。如果剪贴板内容带有仅用于 shell 的外围引号或空格转义，请核对并移除这些包装；实际文件夹名称中的空格应保留。优先使用“选择目录”可减少手工输入错误。

### 同一样本必须有可靠对应关系

- 优先使用相同的相对文件名，其次使用唯一完整文件名，再使用唯一主文件名。例如 `000001.jpg` 与 `000001.png` 可以在主文件名唯一时对应。
- 大小写不同不会被自动当成同一文件；Unicode 名称仅在正规化后唯一时安全匹配。候选有歧义就拒绝匹配。
- 文件夹可含子目录；不能分别排序后把第 N 张当成同一样本。
- 缺失或歧义位置显示 `Missing`，不以别的图片替代。几何视野同步要求各方法确实呈现同一场景；仅分辨率相同不能证明已经配准。
- 请选择实际图片子目录，不要选择整个磁盘或挂载卷根目录，也不要选择符号链接本身。外置磁盘须处于已挂载状态；云盘文件须已实际下载到本机。

## 5. “选择目录”没有弹出窗口

原生目录选择依赖当前 Python 的 Tk 支持。可在终端检查：

```bash
python3 -m tkinter
```

正常时会出现一个 Tk 演示窗口，确认后关闭即可。这是 Python 官方推荐的 Tk 安装诊断方法。[Tkinter 官方说明](https://docs.python.org/3/library/tkinter.html)

如果提示缺少 `_tkinter`、窗口无法打开或选择器超时，仍可直接在欢迎页粘贴图片目录的绝对路径并建立索引。需要原生选择器时，再核对所用 Python 发行版，或安装包含 Tk 的官方 macOS 安装器。不要把选择器失败误认为图片需要转码，也不需要为此重命名原始目录。

## 6. macOS 安全提示与目录权限

对于已核实来源、确认未被篡改的下载文件，如果 macOS 提示开发者无法验证，可先尝试打开，再到“系统设置 → 隐私与安全性”，针对该文件点击“仍要打开”，按系统提示确认。菜单名称会随 macOS 版本变化。[Apple 官方安全打开流程](https://support.apple.com/en-us/102445)

不要全局关闭 Gatekeeper，也不要用递归清除整个下载目录安全属性的方法处理。若系统明确报告恶意软件、文件损坏或组织策略禁止运行，停止打开并核对下载包或联系管理员；普通执行权限与安全检查不能混为一谈。[Apple 对不同安全警告的解释](https://support.apple.com/en-us/102445)

图片目录需要读取权限，工作区需要写入权限。Mac 可能根据所在目录要求你授权终端或 Python 访问文件。优先选择当前用户可以读取的图片目录和可写项目位置，不要为了排查问题随意授予整盘访问权限。若启动器明确发现默认工作区不可写，应用会请求你选择用于索引和收藏的可写文件夹；取消不会自动改写其他用户目录。

## 7. Mac 作为主机，邀请可信内网同学

双击 **`Start-LAN-macOS.command`** 开启内网模式。主机完成目录配置后，从邀请界面复制实际地址与访问口令。同学填写昵称，保存首次生成的恢复码；每人的收藏、备注和已审状态独立保存，主机可以集中查看。

本机启动默认只监听回环地址；内网启动还受允许子网、Host、会话与同源校验限制。切换模式或显式子网范围时，启动器会按实际配置重启旧服务，避免沿用旧开放范围。`127.0.0.1` 不能发给同学当作主机地址。

首次入站访问时，macOS 可能询问是否允许 Python 或应用接收连接；可在“系统设置 → 网络 → 防火墙”核对相关应用规则。保留防火墙，不要整体关闭来排障。[Apple 防火墙说明](https://support.apple.com/en-euro/guide/mac-help/mh34041/mac)

校园网不同 VLAN、客户端隔离、访客网络或路由限制仍可能阻止连接。保持主机开机、避免休眠，先用另一台设备验证。该服务默认 HTTP，没有 TLS 加密，只面向获准查看数据的可信内网用户。完整权限与网络说明见 [内网协作指南](LAN_COLLABORATION.md)。

## 8. 保存、退出与跨系统迁移

- 默认配置、索引、口令和 SQLite 标记保存在项目旁 `local/`；选择了其他工作区时，以实际所选目录为准。它们不属于公开源码，不应提交 GitHub。
- 查看器不修改原始图片、检测框坐标或置信度。建立索引也不会把整个图片集上传或解码。
- 从主机页面点击“退出本地服务”，或在运行服务的终端按 `Control+C` 停止；浏览器刷新和关闭标签页不等于退出。
- 更换电脑或 Windows/Mac 互迁时，先备份原工作区并导出团队标记。图片在目标电脑必须有可访问目录，再重新选择路径；新的路径可能对应新的数据集身份。迁移已有记录时须同时核对数据集 ID 与样本 ID，不能把另一套同名图片的标记混入。

## 9. 当前验证范围

当前已经执行 Windows 上的脚本、服务和跨平台行为模拟测试；macOS 的路径、网卡掩码、Finder 定位命令、启动参数和目录选择输出有自动化模拟覆盖。**尚未在真实 Mac 上运行本项目，也未产出或验证 Mac `.app`，因此不能把模拟测试写成 Mac 实机通过。**

## 10. 2.2：在 Mac 上继续用精选小库

作为主机，在批量小库预览中确认样本与方法，选择 Mac 上已有可写的目标目录；程序在里面新建批次，按方法复制原文件。显示名中的 Windows 非法字符、保留名或同名冲突会通过安全名称映射处理，不会改动原始目录。

作为访问者，先把 ZIP 下载到自己的 Mac，完整解压到本机可写目录。在成功弹窗的“你电脑上已解压的批次目录”填入批次目录本身（它下面直接是方法文件夹），再“下载 MulimgViewer 导入 CSV”。此浏览器步骤不额外需要 Python。Windows 主机盘符与 Mac 路径不能混用；移动目录后再次准备路径，只更改清单，不给图片改后缀或重新编码。

同名且完整的小库可以用 MulimgViewer 并行目录模式；扩展名不一致时，用无表头、每格是本机图像路径的 Image File List CSV，先核对列顺序与样本。批次报告保留 Missing、失败、安全名称映射和未进入兼容 CSV 的样本，不能靠目录排序把缺项补齐。具体入口与操作见[精选小库教程](BATCH_EXPORT.md)。

Mac 路径处理的自动测试仍不等同于 Mac 实机或 MulimgViewer GUI 已验收；当前实际覆盖以 `TESTING.md` 为准。
